# AI name and filing watch review

Review date: 12 October 2026

This is a source-linked filing review, not a live or exhaustive global database scan. It covers recent SEC filers and one HKEX issuer. SEC EDGAR includes foreign issuers that report to the SEC, but it does not cover every foreign public company. HKEX is an issuer-specific example, not a full exchange crawl.

The screen treats AI language as an event to inspect. It does not infer deception or a short recommendation. For each event, compare the legacy business and industry code with the new strategy, then look for assets, customer agreements, commissioning, revenue, gross profit, cash needs, capital raised, dilution, and auditor or going-concern language.

## Automation boundary

The SEC's company submissions API exposes current and former names, ticker symbols, and filing history in JSON without API keys. The SEC says the JSON is updated throughout the day, but `data.sec.gov` does not support browser CORS. Full-text search covers EDGAR filings and exhibits, while SEC documents do not describe a stable full-text JSON search API for this workflow. A reliable monitor should ingest submission history and selected original filings within SEC fair-access limits, and label coverage as SEC filers.

HKEX announcements can be monitored for a finite issuer universe, but this review has not validated a comprehensive, reliable API for exchange-wide automation. Companies House and GLEIF can add jurisdiction-specific name or identity events, but neither is a complete listed-company filings database. Avoid describing any of these feeds as a global corporation database.

The SEC first-pass screen compares AI-language evidence with the prior filing of the same form. It can flag a new operating phrase even when the raw number of AI keyword hits stays flat. The comparison uses keyword-centered sentences, removes generic filing language, and suppresses near-duplicate wording. It still produces leads, not confirmed pivots. New businesses can be missed when they use terms outside the keyword list, and sentence changes can still create false positives. Review the linked filing and prior filing before treating a match as an event.

The automated legal-name screen now requires a recent transition in the SEC submissions `formerNames` history as well as an 8-K Item 5.03 and filing text that corroborates a name change. Leads carry the prior name, current name, history date, and a direct SEC submissions link. The history supports the identity change, not the company's strategic motive. Edge tests cover multiple historical names, ordering, missing end dates, and the 45-day boundary. The public JSON feed still has no successful scan timestamp; GitHub Actions needs the `SEC_USER_AGENT` secret before it can populate the feed.

OpenDART and Brazil CVM adapters are local, manual tools, not live feeds. Their current tests use synthetic or reconstructed fixtures; do not treat those tests as validation against a live exchange archive. The CVM adapter now sorts by filing delivery date before applying the document cap so an archive's physical order cannot silently select older documents.

Sources: [SEC API documentation](https://www.sec.gov/search-filings/edgar-application-programming-interfaces), [SEC full-text search FAQ](https://www.sec.gov/edgar/search/efts-faq.html), [SEC fair-access guidance](https://www.sec.gov/about/developer-resources).

## Follow-up code audit · 13 October 2026

The SEC scanner previously required 8-K Item 5.03 for every legal-name lead. It now also accepts explicit name-change wording in a 6-K, then requires the same independent SEC submissions-history match and effective-date proximity before retaining the lead. This matters for foreign private issuers reporting through 6-K. Tests cover positive and negative 6-K cases and confirm that filing text alone does not establish a name transition.

The phrase list now includes “machine learning” and common AI positioning terms. Matched snippets can show nearby text cues for financial results, customers or contracts, assets/capacity/deployment, funding/dilution, and forward-looking language. These cues are only words near a keyword hit. They are not extracted financial facts and do not establish that AI caused the revenue, contract, facility, or financing mentioned in the same excerpt.

Coverage remains partial. The scheduled feed still scans only SEC filers mapped by the SEC company-ticker-exchange association file. OpenDART Korea and Brazil CVM are separate local/manual adapters, not a combined live international database. The public SEC feed currently has no successful scan timestamp until the GitHub Actions `SEC_USER_AGENT` secret is configured and the job completes. Offline tests do not verify live provider connectivity or filing coverage.
