# Open tools directory tab

The `Open tools directory` tab embeds a local copy of the public directory data from the separate repository at `https://github.com/dring-05/open-access-research-tools`, specifically `src/directory.json`, reviewed 2026-10-12. It contains 220 records. The separate workbook and research notes are not copied. The 70 already-public preview snapshots referenced in the data are stored under `public/open-tools-previews/` so the local directory can show them without loading them from another site.

The page opens on the 76-record curated starting list. Search, sector and technology-niche filters can narrow it. Turn off “Curated starting list” to browse all records. Each row includes free-access notes, coverage, cadence, freshness evidence, and a provider link. Preview pictures are dated snapshots, not live views.

This is a static copy, not a live connection to the other repository. When that directory changes, refresh `public/open-tools-directory.json` from the source repo's current `src/directory.json` and refresh the referenced image files from `public/previews/`. Check the new data and URLs before publishing. The source checkout has no repository license file. This copy mirrors the user's existing public directory, including its preview screenshots; each screenshot remains a dated capture of a third-party page. Provider pages and datasets remain links, and this mirror does not establish reuse rights for those materials.

The brand shown in this repository is now **Dashboard**. The GitHub repository name and Cloudflare Worker name remain implementation identifiers.
