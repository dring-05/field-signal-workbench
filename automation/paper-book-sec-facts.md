# Paper Book SEC fundamentals helper

paper-book-sec-facts.gs and paper-book-idea-form.html add a custom Paper Book menu and guided idea-entry sidebar to the private workbook's bound Apps Script project. The form records company, ticker, exchange, book, side, target NAV weight, conviction, thesis, operating signal, metric bridge, falsifier, and optional research links. It adds an editable Ideas row, links a Valuation Inputs row, and can refresh standardized reported fundamentals. When a private parent folder is configured, it creates a private subfolder for the idea. It does not place trades, fetch prices, or publish private book data.

## Setup

1. Open the private Paper Book spreadsheet and choose Extensions, Apps Script. Add `paper-book-sec-facts.gs` as a new script file and `paper-book-idea-form.html` as an HTML file with that exact name. Keep existing workbook code and triggers. This module defines `paperBookAddMenu_` instead of claiming the project's `onOpen` name. If the project already has an `onOpen` handler, add `paperBookAddMenu_();` inside it. If it has no `onOpen` handler, add a small `onOpen` function that calls `paperBookAddMenu_();`.
2. In Apps Script Project Settings, Script Properties, set `PAPER_BOOK_SPREADSHEET_ID` to the private workbook ID, `PAPER_MATERIALS_PARENT_FOLDER_ID` to the private materials folder ID, and `SEC_USER_AGENT` to an identifying label and your real contact email. The email stays in Script Properties and is not in this source file. The SEC requests an identifying User-Agent and limits users to 10 requests per second. A submission refresh makes two sequential requests and caches the public ticker map for six hours. Leave the materials parent unset if you do not want the script creating subfolders.
3. Save and reload the spreadsheet. Choose Paper Book, Add an idea to open the guided form. Submission writes to the private Ideas tab, creates a stable Idea ID and a linked valuation row, then refreshes SEC facts if configured. With a materials parent configured, it makes a subfolder that inherits the parent's Google Drive access. If SEC access is not configured or a fetch fails, the saved idea remains and the valuation row records the issue. Direct edits in Ideas can also use the installable edit trigger described below.
4. To enable that trigger, choose Paper Book, Install idea-entry trigger once and approve Google's Apps Script authorization prompt. When Company name and Ticker are entered directly in an Ideas row, the trigger creates an Idea ID if blank, links a Valuation Inputs row, and refreshes SEC facts when configured. It never replaces a nonblank Idea ID.
5. Select an idea row in Ideas or its valuation row, then choose Paper Book, Refresh selected idea from SEC. Read the alert for missing tags or a ticker/exchange mismatch.

Choose Paper Book, Mark selected idea Exited to keep the idea row and transaction history while setting its status and exit date. Add the actual closing fill separately in Transactions. This status change does not infer fills or book returns.

## Workbook behavior

The workbook has headers on row 5 and records beginning on row 6. The helper matches the Ideas columns Idea ID, Company name, Ticker, Exchange, and Sector, and matches valuation rows by Idea ID. It requires the Valuation Inputs headers Valuation record ID, Idea ID, Ticker / exchange, Shares outstanding, Share-count date/source, TTM net income, Cash & equivalents, Total debt, TTM EBITDA, TTM revenue, Total equity, and Fundamentals source and period.

When creating a new valuation row, it reuses an empty formula-prefilled row where available, ignoring formula-only cells when checking whether a row contains user data. It fills the record identifiers, copies row 6 formatting and validation when needed, and seeds formula columns from the first data row where possible. Missing formula templates are seeded for market capitalization, P/E, enterprise value, EV/EBITDA, P/S, P/B, P/FFO, and the suggested sector metric. Formula outputs depend on their source inputs. In particular, the share price remains manual, so market capitalization and price-based multiples are blank until a price is entered. The SEC refresh writes only shares outstanding, share-count source/date, TTM net income, cash and equivalents, total debt, TTM EBITDA, TTM revenue, total equity, and the fundamentals provenance note. It leaves price, price source, valuation formulas, thesis, book size, conviction, and other user-maintained fields unchanged.

## Source and calculation limits

The helper resolves tickers through the SEC's public ticker and exchange file, then requests the official Company Facts JSON for that CIK. It uses standard US-GAAP facts where available. A TTM flow is the sum of four consecutive reported quarters. When a company reports cumulative year-to-date flows, it derives standalone quarters by subtracting the preceding cumulative period. Incomplete or discontinuous periods are left blank. EBITDA is reported operating income plus reported depreciation and amortization. Debt uses a non-overlapping complete current and noncurrent pair, or a total debt tag where available.

SEC Company Facts does not provide market prices. It may lack sector-specific or issuer-extension concepts, including REIT FFO/AFFO, and standard facts do not cover every non-US listing or taxonomy. The helper does not synthesize those fields or assume a generic metric is appropriate for banks, insurers, REITs, or other sectors. A blank value with an explanation means the helper could not identify a sufficiently complete standardized fact series. Check the linked SEC filing and the stated tag, period, CIK, and share-count date before relying on a multiple.

The SEC says Company Facts contains entity-wide facts using standard taxonomies, is updated as filings are disseminated, and does not support CORS. This helper calls SEC endpoints from Apps Script, not from the public site. There is no free broad quote feed verified for this professional workflow, so price stays manual with its date, source, and currency. Google Finance says its data is not intended for financial-industry professional use. Do not use it here without compliance approval. References: [EDGAR API documentation](https://www.sec.gov/search-filings/edgar-application-programming-interfaces), [SEC ticker and exchange mapping](https://www.sec.gov/files/company_tickers_exchange.json), [SEC fair-access guidance](https://www.sec.gov/developer), and [Google Finance function restrictions](https://support.google.com/docs/answer/3093281).

## Local test

From the repository root, run node tests/check-paper-book-sec-facts.mjs. The fixture checks ticker mapping and ambiguity, direct quarterly and cumulative YTD TTM arithmetic, revisions, debt aggregation, missing tags, row-5 headers and row-6 records, reusing formula-only rows, and that the SEC refresh only writes the intended SEC-derived columns. It makes no network call and does not access the private spreadsheet.
